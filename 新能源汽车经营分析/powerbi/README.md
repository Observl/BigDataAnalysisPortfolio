# EV BI：导入与页面说明

## 导入数据

在 Power BI Desktop 选择“获取数据 → Excel 工作簿”，导入本文件夹下的 `新能源汽车经营分析_PowerBI聚合数据.xlsx`，并勾选所需工作表。`整体市场月度销量` 代表整体汽车市场月度销量；车型明细及其汇总均为样本口径，需在页面副标题标注。

## 三页结构

1. **市场概览**：整体市场月度销量及同比；新能源汽车车型样本年度销量卡片和趋势图。
2. **厂商与车型**：按年份的厂商样本销量排名、厂商样本份额趋势、车型销量 Top N。
3. **价格与数据边界**：车型销量与售价区间的明细表、数据质量表，并明确“样本销量不等于全市场销量”。

## 可用 DAX

```DAX
总体市场销量 = SUM('overall_market_monthly'[销量])
新能源车型样本销量 = SUM('ev_model_monthly'[销量])
新能源厂商样本份额 = DIVIDE(
    [新能源车型样本销量],
    CALCULATE([新能源车型样本销量], ALL('ev_model_monthly'[厂商]))
)
```

不把历史拟合结果表达为正式预测，也不将同期相关性写成因果结论。若需要预测或竞争归因，应补充外部数据、明确预测窗口，并独立验证。
