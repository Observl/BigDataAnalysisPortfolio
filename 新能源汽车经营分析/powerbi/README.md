# EV BI：导入与页面说明

## 导入数据

在 Power BI Desktop 选择“获取数据 → Excel 工作簿”，导入本文件夹下的 `新能源汽车经营分析_PowerBI聚合数据.xlsx`，并勾选所需工作表。`整体市场月度销量` 代表整体汽车市场月度销量；车型明细及其汇总均为样本口径，需在页面副标题标注。`EV BI.pbix` 是可直接打开的报表文件；`EV BI.pbip` 及同名 Report、SemanticModel 文件夹是编辑版，修改磁盘文件后应关闭并重新打开 Desktop，再核验页面和刷新结果。

## 三页结构

1. **市场概览**：整体市场月度销量及同比；新能源汽车车型样本年度销量卡片和趋势图。
2. **厂商与车型**：按年份的厂商样本销量排名、厂商样本份额趋势、车型销量 Top N。
3. **价格与数据边界**：车型销量与售价区间的明细表、数据质量表，并明确“样本销量不等于全市场销量”。

## 度量值示意（建模前先核对实际表名与列名）

```DAX
总体市场销量 = SUM('overall_market_monthly'[销量])
新能源车型样本销量 = SUM('ev_model_monthly'[销量])
新能源厂商样本份额 = DIVIDE(
    [新能源车型样本销量],
    CALCULATE([新能源车型样本销量], ALL('ev_model_monthly'[厂商]))
)
```

以上 DAX 是按示意表名写的草案，不代表当前 PBIX/PBIP 中已创建这些度量值。建立前先查看实际导入工作表及字段，避免重复定义。看板中不把历史拟合结果表达为正式预测，也不将同期相关性写成因果结论。若需要预测或竞争归因，应补充外部数据、明确预测窗口，并独立验证。
