# 新能源汽车经营分析

本项目整理中国新能源汽车与整体汽车的月度销量资料，构建面向经营复盘的分析 Notebook。当前在线报告仅呈现 Notebook 中已经保存的检查输出和两张总体趋势图；其余品牌、车型、异常监控与月度摘要模块仍是待完善的分析框架，不应视为已验证的经营结论。

**在线查看：** [GitHub Pages 交互式报告](https://observl.github.io/BigDataAnalysisPortfolio/nev/)

## 数据与边界

- 数据来自项目目录中的中国电动汽车、整体汽车及总体销量 Excel 文件和随附说明。
- 已保存输出显示，车型和厂商月度记录的检查区间截至 2023 年 9 月；Notebook 中的数据说明仍标注源资料可能覆盖至 2023 年 11 月，发布前需要重新核对口径与实际截止时间。
- 销量、同比、环比、份额和排名可以描述样本中的变化，不能单独证明价格、促销、政策、渠道或产能等原因。
- 2023 年若非完整年度，只能与上一年同期比较，不能直接与完整年度比较。

## 当前模块

1. 导入、字段、时间连续性、缺失值、重复值与负销量检查。
2. 整体汽车与新能源汽车的月度、年度销量趋势交互图。
3. 品牌、车型、异常波动、可筛选看板和月度摘要的指标口径与待完成框架。

## 技术方案

使用 Python、Pandas、NumPy、DuckDB 与 Plotly。Notebook 以月度、厂商/品牌、车型等粒度组织数据；在线报告使用仓库内的 Plotly 前端运行时展示已经保存的交互图，不执行 Notebook 或重新计算数据。
