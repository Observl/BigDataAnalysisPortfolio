# Brazil E-Commerce BI：导入与页面说明

在 Power BI Desktop 选择“获取数据 → Excel 工作簿”，导入本文件夹下的 `巴西电商分析_PowerBI聚合数据.xlsx`。订单事实表已将订单、客户、支付、评价与商品金额合并，适合直接作为主事实表。

## 三页结构

1. **订单概览**：订单数、已交付订单数、商品收入（不含运费）、客户数；按状态和月份的订单趋势。
2. **品类表现**：品类收入、订单数与评价分布；使用 Top N 和日期筛选器。
3. **履约与体验**：承诺时效、实际交付时效、延迟交付订单占比，以及评价分布。先在 Power Query 检查日期和空值类型。

`item_revenue` 只汇总商品金额，明确不含 freight value；退款、毛利与营销归因不在现有数据范围内。
