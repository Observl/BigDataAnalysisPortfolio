# Brazil E-Commerce Analysis

## 项目目标

基于 Olist 巴西电商公开数据，构建从订单、客户、商品、卖家、支付、履约到评价的可复现分析项目。项目用于回答销售表现、客户复购、商品与卖家结构、交付体验和评价之间的描述性关系；不将观察性关系表述为因果结论。

## 数据范围

- 数据位于 `source_data/archive/`，包含订单、订单商品、支付、评价、客户、商品、卖家、地理及品类翻译表。
- 订单主表的时间字段定义分析观察期；运行分析前以实际最小/最大日期为准。
- 订单、客户、商品、卖家之间按数据集提供的 ID 关联；订单商品为一单多行粒度。

## 分析模块

1. 数据质量与关系完整性：主键重复、连接覆盖率、缺失、时间顺序和订单状态。
2. 销售与订单：订单量、商品金额、运费、支付方式和状态结构。
3. 客户：去重客户、复购、RFM 和队列留存。
4. 商品与卖家：品类、客单价、卖家结构和集中度。
5. 履约与体验：交付时长、晚到、评价与运费的描述性比较。
6. Power BI：管理概览、客户价值、履约体验和数据质量页面。

## 运行方式

```powershell
pip install -r requirements.txt
python analysis\build_analysis.py
```

脚本读取 `source_data/archive/` 中的本地 CSV；看板导入使用 `powerbi/` 中的单一 Excel 聚合工作簿，原始数据不被修改。

## 交付物

- `analysis/`：可复现 Python 分析脚本。
- `data/README.md`：数据字典、模型关系和口径。
- `powerbi/`：中文命名的看板导入数据、数据质量报告、页面规格和 PBIX 文件。

## 限制

- 所有金额、订单状态、交付和评价结论仅适用于数据集观察期与记录范围。
- 缺少完整营销曝光和利润成本数据，不能直接衡量营销归因或净利润。
- 交付、运费与评价之间仅做描述性比较，不能单独证明因果关系。
