# 淘宝用户购物行为分析

## 项目简介

基于淘宝公开用户行为日志，对 2017 年 11 月 25 日至 12 月 3 日、约 98.8 万名用户的超过 1 亿条浏览、收藏、加购和购买记录进行探索性分析。项目聚焦样本期内的行为结构、时间节律、商品表现与用户差异，展示从大规模数据处理到业务解释的完整流程。

[查看 GitHub Pages 交互式报告](https://observl.github.io/BigDataAnalysisPortfolio/taobao/)

## 技术方案

原始 CSV 为数 GB、亿级记录，项目使用 DuckDB 建立本地分析库，以 SQL 完成去重、缺失与异常处理、时间特征提取及指标聚合；再使用 Pandas 与 Plotly 展示结果，并使用 Scikit-learn 的 K-Means 进行探索性用户分群。

> 数据导入与清洗 → SQL 指标聚合 → 交互式可视化 → 用户分群 → 业务假设

## 分析模块

1. **宏观行为结构**：汇总浏览、收藏、加购与购买行为次数，识别浏览与明确意向行为之间的数量差距。
2. **时间行为分析**：按日期、星期、工作日/周末和小时观察互动量与浏览—购买行为次数比；小时柱图使用固定行为色，并以颜色强弱提示当小时的互动规模。
3. **商品价值分析**：对独立浏览用户数超过 5,000 的商品和类目，按浏览规模与浏览—购买行为次数比构建四象限，形成商品分层观察视角。
4. **用户价值分析**：以互动过的不同商品数、样本期活跃天数和购买行为次数为特征，使用 K-Means 划分高价值、常规与非核心行为群体。

## 主要发现与业务含义

- 收藏与加购行为次数合计约为浏览次数的 9.3%，购买行为次数约为浏览次数的 2.23%；这些是汇总行为次数比，不是严格的路径转化率。
- 3—5 点为互动低谷，20—22 点为互动高峰；10—12 点的浏览—购买行为次数比相对较高，说明流量规模与购买行为效率并不完全同步。
- 商品四象限可用于提出候选策略：为低流量高表现商品测试更多曝光，检查高流量低表现商品的推荐匹配与详情页信息质量。
- 用户分群可支持高价值用户维护、常规用户培养及低互动用户的低成本召回。

上述运营动作均是观察性分析形成的待验证假设，需通过路径级漏斗、留存指标或 A/B 测试确认实际效果。

## 分析边界

- 观察期仅 9 天，不能外推长期增长、季节规律或稳定营销时段。
- 行为次数无法确认同一用户购物路径中的严格先后关系。
- 数据缺少订单金额、客单价与商品属性，不能分析营收贡献，也不能构建完整 RFM。
- 聚类仅反映样本期行为活跃度，不等同于长期用户价值。
