# 淘宝用户购物行为分析

## 项目简介

本项目基于淘宝公开用户行为数据，分析 2017 年 11 月 25 日至 12 月 3 日共 9 天内约 100 万名用户产生的 1 亿条浏览、收藏、加购和购买记录，探索用户行为结构、小时级活动规律、商品表现与用户分层。

项目属于探索性作品集分析，重点展示大规模数据处理、指标设计、可视化和业务解释能力。分析结果仅适用于当前样本期，不用于判断淘宝的长期经营趋势，也不代表因果关系或正式营收预测。

**在线查看：** [GitHub Pages 交互式分析报告](https://observl.github.io/BigDataAnalysisPortfolio/taobao/)

## 技术方案

**技术栈：** Python、DuckDB、SQL、Pandas、Plotly、Scikit-learn

原始 CSV 文件达到数 GB、包含约 1 亿行记录，直接使用 Pandas 全量读取容易占用大量内存。因此，本项目使用 DuckDB 建立本地分析数据库，通过 SQL 完成数据清洗、时间特征提取和指标聚合，再使用 Plotly 制作交互式图表，并通过 K-Means 探索用户分层。

> 数据导入与清洗 → SQL 指标聚合 → 交互式可视化 → 用户分群 → 业务分析

## 分析内容与主要发现

### 1. 宏观行为分析

对浏览、收藏、加购和购买行为进行整体汇总。样本期内收藏与加购次数合计约为浏览次数的 **9.3%**，购买次数约为浏览次数的 **2.23%**，浏览与明确意向行为之间存在较大的数量差距。

这些指标是不同类型行为的次数比，并非同一用户购物路径上的严格转化率。推荐优化、商品信息完善和高意向用户触达可以作为候选策略，实际效果仍需通过路径级漏斗和 A/B 测试验证。

### 2. 小时行为分析

用户行为呈现明显的昼夜节律：**3—5 点为互动低谷，20—22 点为互动高峰**。购买与浏览行为次数比在 10—12 点表现较高，说明流量规模最高的时段并不一定也是购买行为效率最高的时段。

业务上可针对不同时段设计差异化实验，例如在日间测试购买决策促进策略，在晚间重点承接流量并触达收藏、加购用户，而不是仅根据流量规模分配运营资源。

### 3. 商品价值分析

对独立浏览用户数超过 5,000 的商品和类目进行分析，根据浏览规模与购买表现观察其分布，并从商品分层角度识别高流量高表现、低流量高表现、高流量低表现和低流量低表现的商品。

该分析可用于提出候选运营动作：为潜力商品测试更多曝光，为高流量低表现商品检查推荐人群与详情页质量，并为表现稳定的核心商品保障曝光。由于分析只覆盖筛选后的高流量样本，这些结论不代表平台全部商品。

### 4. 用户价值分析

由于数据缺少订单金额，本项目使用用户互动过的不同商品数、活跃天数和购买行为次数作为特征，通过 K-Means 将用户划分为**高价值、常规和非核心**三类行为群体。其中，活跃天数指用户在样本期内发生过行为的不同自然日数量。

分群结果可支持差异化运营假设：维护高价值用户、培养常规用户，并对低互动用户开展低成本召回。这里的“价值”代表样本期内的行为活跃程度，不等同于收入贡献或长期用户价值。

## 项目亮点

- 使用 DuckDB 和 SQL 完成数 GB、亿级行为数据的清洗与聚合。
- 使用 Plotly 展示行为结构、小时规律以及商品和用户分布。
- 将业务问题转化为可计算指标，并主动区分行为次数比与严格转化率。
- 结合商品分层和用户分群提出可验证的业务假设，而非直接作出因果判断。
- 完成从数据处理、指标构建、分析建模到业务表达的完整分析流程。

## 分析边界与下一步

- 观察窗口只有 9 天，无法外推长期增长趋势或季节规律。
- 数据缺少订单金额、客单价和商品属性，不能直接分析营收贡献或建立完整 RFM 模型。
- 汇总行为次数无法确认同一次购物路径的严格先后关系。
- 用户聚类仅反映样本期行为，仍需验证稳定性和长期区分能力。

后续可进一步构建路径级行为漏斗和用户留存分析，检验聚类稳定性，并在获得订单金额后开展 RFM 与用户生命周期价值分析。

## 项目运行

分析 Notebook：[淘宝用户购物行为分析.ipynb](./淘宝用户购物行为分析.ipynb)

数据来源：[阿里云天池——淘宝用户购物行为数据集](https://tianchi.aliyun.com/dataset/649)

1. 安装 Python 3 和 Jupyter Notebook。
2. 安装项目依赖：

   ```bash
   pip install pandas duckdb plotly scikit-learn jupyter
   ```

3. 下载数据并将 `UserBehavior.csv` 放入本目录。
4. 在本目录启动 Notebook，并按顺序运行全部单元格：

   ```bash
   jupyter notebook "淘宝用户购物行为分析.ipynb"
   ```

首次运行会在本地创建 `UserBehavior.db`。原始 CSV 与数据库文件体积较大，已通过 `.gitignore` 排除，不随 Git 仓库提交。
