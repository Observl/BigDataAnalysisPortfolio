# Taobao BI：导入与页面说明

## 导入数据

在 Power BI Desktop 选择“获取数据 → Excel 工作簿”，导入本文件夹下的 `淘宝用户购物行为分析_PowerBI聚合数据.xlsx`，并勾选全部四个工作表。一个工作簿集中存储核心指标、每日行为趋势、小时行为趋势和类目转化漏斗。

数据为聚合表，不导入 3.7GB 原始行为明细。日期列设为“日期”；小时、次数、用户数设为“整数”；比例列设为“小数/百分比”。

## 三页结构

1. **经营概览**：卡片显示总用户数、总浏览次数、总购买次数、浏览与购买行为次数比；使用漏斗图呈现浏览、收藏、加购、购买。
2. **时间规律**：日趋势折线图展示浏览与购买次数；小时组合图展示行为量，并以折线叠加“浏览与购买行为次数比”。
3. **类目机会**：散点图使用 `category_funnel`，横轴为独立浏览用户数、纵轴为浏览转购买率、气泡大小为独立购买用户数；筛选器限制最低浏览量，避免小样本误导。

## 指标边界

`浏览与购买行为次数比` 是同一观察窗口内的行为次数之比，不是逐用户、逐会话的严格漏斗转化率。看板应保留这一说明；没有价格、订单金额和会话 ID，不能呈现 GMV、客单价或严格转化归因。
