## 使用说明

- 各项目的分析口径、数据范围、运行方法和局限性见项目目录内 README。
- 原始 CSV、Excel 与 DuckDB 数据库文件体积较大，不随 Git 仓库提交；请按各项目说明准备本地数据后再运行 Notebook。
- 所有分析结论均基于对应样本与观察窗口，属于描述性或探索性发现，不直接代表长期趋势、经营因果或营收结果。
