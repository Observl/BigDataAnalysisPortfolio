在线购物点击流分析

这份报告分析一家服装网店在 2008 年 4 至 8 月的浏览记录，依次查看访问量、会话深度、品类切换，以及商品和页面的点击分布。

1. 数据与准备

原始文件为 source_data/e-shop clothing 2008.csv，使用分号分隔。每行记录一次商品点击，session ID 标识会话，order 表示会话内的点击顺序，price 为美元标价。字段解释见同目录的 e-shop clothing 2008 data description.txt。

先读取日志、补充日期和中文标签，再按会话与点击序号排序。

Python 代码
daily = df.groupby('date').agg(clicks=('step','size'),sessions=('session_id','nunique')).reset_index()

categories = df.groupby('category').agg(clicks=('step','size'),sessions=('session_id','nunique'),products=('product','nunique'),mean_price=('price','mean')).reindex(list(category_map.values())).reset_index()
categories['click_share'] = categories['clicks']/len(df)
countries = session.groupby('country').agg(sessions=('clicks','size'),clicks=('clicks','sum'),mean_depth=('clicks','mean'),median_depth=('clicks','median')).sort_values('clicks',ascending=False).reset_index()
products = df.groupby('product').agg(clicks=('step','size'),sessions=('session_id','nunique'),category=('category','first'),price_min=('price','min'),price_max=('price','max')).sort_values(['clicks','product'],ascending=[False,True]).reset_index()
products['cum_share'] = products['clicks'].cumsum()/len(df)

df['next_category'] = df.groupby('session_id')['category'].shift(-1)

transition_rates=transition_counts.div(transition_counts.sum(axis=1),axis=0)

8. 推荐优化与 A/B 测试

8.1 优化首个商品页的相关推荐

单点击会话占约 21%，相邻点击约 81% 留在同一品类。本专题选择首个商品页的推荐排序：A 方案展示全站热门商品，B 方案展示当前品类的热门商品。两组均显示三件商品，排除当前商品，卡片样式和位置一致。

8.2 按时间划分训练、验证和测试

8.5 线上实验怎么分流与验收

项目 预先约定
实验对象 第一次触发商品页推荐的合格访客
分流单位 匿名访客 ID；同一访客在实验期间固定 A / B，比例 50:50
入组时点 首个商品页推荐请求发出前，写入分组记录
观察范围 该访客首次合格会话，入组后 60 分钟
主指标 继续浏览率：观察期内商品浏览事件达到 2 次的访客 / 全部入组访客
统计方案 双侧 α=0.05，功效 80%，固定样本；主指标差值为 B-A
业务门槛 继续浏览率至少提高 2 个百分点
护栏 B 组商品页加载耗时 P95 不超过 A 的 105%，渲染错误率上升不超过 0.5 个百分点
运行条件 两组达到预设样本量，且完整运行至少 14 天；入组截止后等待全部观察窗口结束
上线条件 主指标 95% 差值区间下限大于 0、点估计达到业务门槛，且护栏通过

分流使用 abtest/experiment.py 的 assign_group，输入固定的匿名访客 ID。事件按 event_id 去重，每名访客只保留首次合格会话。两组共享同一份预先冻结的热度表；实验期间只改变排序规则。正式判定前，日常检查分流比例、埋点完整性和性能。
