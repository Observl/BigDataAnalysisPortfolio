新能源汽车经营分析

项目概述

这是一个面向实习面试的新能源汽车销售数据分析项目。项目使用中国整体汽车和新能源汽车的月度销量数据，从市场趋势、品牌竞争、车型结构和价格区间四个角度观察新能源汽车行业的发展情况。

目前已完成数据检查与清洗、宏观销量趋势、年度品牌销量与市场份额、车型销量与品牌产品结构，以及新能源汽车销量加权价格分析。项目以历史数据研究和交互式展示为主，不将销量变化直接解释为企业经营行为或因果关系。

数据范围

项目内容
整体汽车数据2015年1月—2023年9月，共49,344条记录
新能源汽车数据2015年1月—2023年10月，共9,732条记录
对比分析范围两类数据共有的105个月；2015—2022年为完整年度，2023年为1—9月
统计粒度年—月—厂商—车型
指标单位销量单位为辆，售价区间单位为万元
数据来源项目目录中的两份Excel销售数据
更新方式静态历史数据，暂未接入自动更新

数据中没有独立的品牌字段，因此本项目暂以厂商作为品牌分析的代理口径。涉及整体汽车与新能源汽车对比时统一使用共同月份，避免统计期间不同造成失真。

经营分析目标

  1. 比较整体汽车与新能源汽车的月度、年度销量趋势，观察新能源汽车渗透率和市场增长情况。
  2. 分析整体汽车行业与新能源汽车行业的品牌销量、市场份额和年度排名，了解竞争格局的变化。
  3. 识别新能源汽车年度销量TOP5车型，并通过品牌—车型层级观察各品牌TOP3车型及产品集中度。
  4. 使用车型销量作为权重，计算新能源汽车年度加权平均最低价和最高价，观察主流销售价格区间的变化。
  5. 以特斯拉为案例，从市场地位、增长表现、产品结构、价格定位和竞争关系五个方面建立企业战略分析框架。
  6. 使用Pandas完成数据处理，并通过Plotly年份滑条和交互图表展示结果；解读时区分数据观察、战略含义和待验证假设。

数据来源与确认结果

数据文件记录数实际时间范围主要用途

两份数据均包含年份、月份、排名、厂商、车型、销量和售价区间字段。数据库文件用于保存读取后的中间表，不改变原始Excel文件。跨市场比较统一使用两份数据共有的年月；新能源汽车单独分析也沿用该范围，保证各章节口径一致。

售价为0.00 - 0.00的记录保留其销量，但视为缺失报价，不参与销量加权价格计算。数据文件没有注明采集日期，因此不将文件修改时间作为数据更新时间。

# 按年份的整体汽车销量、新能源汽车销量、渗透率和增长贡献率分析

from plotly.subplots import make_subplots

# 1. 统一两类数据的统计月份
common_year_periods = (v_df[["year", "month"]].drop_duplicates()
                       .merge(ev_df[["year", "month"]].drop_duplicates(), on=["year", "month"]))
v_year_scope = v_df.merge(common_year_periods, on=["year", "month"])
ev_year_scope = ev_df.merge(common_year_periods, on=["year", "month"])

# 2. 按年份汇总整体汽车销量
v_sales_year = (
    v_year_scope.groupby("year", as_index=False)["sales"]
    .sum()
    .rename(columns={"sales": "整体汽车销量"})
)

# 3. 按年份汇总新能源汽车销量
ev_sales_year = (
    ev_year_scope.groupby("year", as_index=False)["sales"]
    .sum()
    .rename(columns={"sales": "新能源汽车销量"})
)

# 4. 合并两类销量数据
year_summary = (
    v_sales_year
    .merge(ev_sales_year, on="year", how="inner")
    .sort_values("year")
    .reset_index(drop=True)
)

# 5. 计算新能源汽车销量占整体汽车销量的比例
year_summary["新能源汽车占比"] = (
    year_summary["新能源汽车销量"]
    / year_summary["整体汽车销量"]
)

# 6. 使用NumPy拟合Logistic S型曲线
fit_year = year_summary["year"].to_numpy(dtype=float)
fit_x = fit_year - fit_year.min()
fit_y = year_summary["新能源汽车占比"].to_numpy(dtype=float)
best_fit = None

for upper_limit in np.linspace(fit_y.max() + 0.01, 1, 2000):
    logit_y = np.log(fit_y / (upper_limit - fit_y))
    growth_rate, intercept = np.polyfit(fit_x, logit_y, 1)
    fitted_y = upper_limit / (1 + np.exp(-(growth_rate * fit_x + intercept)))
    error = np.sum((fit_y - fitted_y) ** 2)
    if best_fit is None or error < best_fit[0]:
        best_fit = (error, upper_limit, growth_rate, intercept)

fit_error, fit_limit, fit_k, fit_b = best_fit

# 计算新能源汽车年度销量加权价格
ev_price_scope = ev_model_scope.copy()
price_range = ev_price_scope["price"].astype(str).str.extract(r"^\s*(\d+(?:\.\d+)?)\s*-\s*(\d+(?:\.\d+)?)\s*$").astype(float)
ev_price_scope[["low_price", "high_price"]] = price_range
valid_price = ev_price_scope[["low_price", "high_price"]].gt(0).all(axis=1)

valid_sales = ev_price_scope.loc[valid_price].copy()
valid_sales["最低价加权额"] = valid_sales["low_price"] * valid_sales["sales"]
valid_sales["最高价加权额"] = valid_sales["high_price"] * valid_sales["sales"]
price_year = valid_sales.groupby("year", as_index=False).agg(有效报价销量=("sales", "sum"), 最低价加权额=("最低价加权额", "sum"), 最高价加权额=("最高价加权额", "sum"))
price_year = price_year.merge(ev_price_scope.groupby("year", as_index=False)["sales"].sum().rename(columns={"sales": "新能源汽车销量"}), on="year")
price_year["加权平均最低价"] = price_year["最低价加权额"] / price_year["有效报价销量"]
price_year["加权平均最高价"] = price_year["最高价加权额"] / price_year["有效报价销量"]
price_year["有效价格销量覆盖率"] = price_year["有效报价销量"] / price_year["新能源汽车销量"]

企业战略分析（特斯拉视角）

分析目的

从特斯拉视角回看2015—2023年中国新能源汽车市场，判断其市场地位、增长质量、产品依赖和价格定位，并据此整理可以由现有销量数据支持的战略信号。2023年统一使用1—9月数据。

本节只根据销量、市场份额、车型和售价区间进行分析。品牌战略、降价原因、产能、利润和消费者偏好需要补充外部资料后才能验证。

1. 特斯拉的市场地位

  • 统计特斯拉年度销量、市场份额和行业排名。
  • 比较特斯拉销量增速与新能源汽车市场整体增速。
  • 观察其市场份额变化是由自身销量变化还是行业扩张速度差异造成。
  • 建议图表：年度销量与市场份额双轴图、品牌排名变化图。

2. 增长表现与稳定性

  • 比较特斯拉年度销量增量、同比增长率和月度销量波动。
  • 识别增长较快、放缓或明显波动的年份和月份。
  • 与新能源市场整体走势比较，判断特斯拉是领先市场增长还是随行业共同变化。
  • 建议图表：月度销量趋势图、特斯拉与市场增速对比图。

3. 产品结构与车型依赖

  • 统计Model 3、Model Y等车型的年度销量和品牌内贡献率。
  • 计算特斯拉TOP1、TOP2车型集中度，观察销量是否依赖少数车型。
  • 比较不同车型的增长阶段和销量重心变化。
  • 建议图表：车型销量堆叠图、车型贡献率趋势图。

4. 价格定位

  • 计算特斯拉车型的销量加权最低价和最高价。
  • 与新能源汽车市场加权价格区间及主要竞争品牌进行比较。
  • 观察价格区间变化与销量、份额变化是否在时间上同步。
  • 价格变化只能作为相关信号，不能直接认定为销量变化的原因。
  • 建议图表：特斯拉与市场加权价格双折线、价格—销量散点图。

5. 主要竞争关系

  • 以年度新能源汽车销量和市场份额排名选择对标企业，比亚迪作为核心对标，其他企业根据实际排名确定。
  • 比较销量规模、增速、份额、车型数量、车型集中度和加权价格区间。
  • 区分特斯拉的直接价格竞争者、规模领先者和产品结构差异较大的企业。
  • 建议图表：重点品牌指标对比表、销量增速—市场份额四象限图。

7. 分析结论框架

  1. **市场位置**：特斯拉当前所处的竞争梯队及变化。
  2. **增长来源**：增长主要来自市场扩张、份额提升还是重点车型。
  3. **核心优势**：由数据支持的规模、产品或价格定位优势。
  4. **主要风险**：份额、增速、车型集中度或价格覆盖方面的风险。
  5. **后续验证**：形成战略判断前必须补充的数据和验证方法。

数据限制与后续方向

  • 整体汽车数据截至2023年9月，新能源汽车数据截至2023年10月；跨市场和年度对比统一按共同月份统计，2023年仅包含1—9月。
  • 数据中的厂商暂作为品牌代理，无法进一步区分集团、品牌和子品牌口径。
  • 部分早期记录的售价为0.00 - 0.00，加权价格分析已排除这些报价，但2015—2018年的有效价格销量覆盖率较低。
  • 销量和市场份额能够描述市场表现，但不能单独解释价格调整、产品改款、渠道变化或消费者选择的原因。
  • 2023年不是完整年度，不能直接与此前完整年度进行全年总量比较。
  • 特斯拉战略分析属于基于销售数据的初步判断，后续仍需补充价格调整、配置、促销、渠道、产能、库存、政策和消费者数据。
  • 后续可继续增加同比/环比异常监控、月度经营摘要，以及用于Power BI或Tableau的指标表。
