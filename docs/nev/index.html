EV经营分析

项目概述

这是一个面向实习面试的EV销售数据分析项目。项目使用中国整体汽车和EV的月度销量数据，从市场趋势、品牌竞争、车型结构和价格区间四个角度观察EV行业的发展情况。

目前已完成数据检查与清洗、宏观销量趋势、年度品牌销量与市场份额、车型销量与品牌产品结构，以及EV销量加权价格分析。项目以历史数据研究和交互式展示为主，不将销量变化直接解释为企业经营行为或因果关系。

数据范围

项目 内容
整体汽车数据 2015年1月—2023年9月，共49,344条记录

对比分析范围 两类数据共有的105个月；2015—2022年为完整年度，2023年共同观测期为1—9月
统计粒度 年—月—厂商—车型
指标单位 销量单位为辆，售价区间单位为万元
数据来源 项目目录中的两份Excel销售数据

经营分析目标

  1. 比较整体汽车与EV的月度、年度销量趋势，观察EV渗透率和市场增长情况。
  2. 分析整体汽车行业与EV行业的品牌销量、市场份额和年度排名，了解竞争格局的变化。
  3. 识别EV年度销量TOP5车型，并通过品牌—车型层级观察各品牌TOP3车型及产品集中度。
  4. 使用车型销量作为权重，计算EV年度加权平均最低价和最高价，观察主流销售价格区间的变化。
  5. 以特斯拉为案例，从市场地位、增长表现、产品结构、价格定位和竞争关系五个方面建立企业战略分析框架。
  6. 使用Pandas完成数据处理，并通过Plotly年份滑条和交互图表展示结果；

# 5. 计算EV销量占整体汽车销量的比例
year_df["EV占比"] = (

# 6. 使用NumPy拟合Logistic S型曲线
fit_year = year_df["year"].to_numpy(dtype=float)
fit_x = fit_year - fit_year.min()
fit_y = year_df["EV占比"].to_numpy(dtype=float)
best_fit = None

for upper_limit in np.linspace(fit_y.max() + 0.01, 1, 2000):
    logit_y = np.log(fit_y / (upper_limit - fit_y))
    growth_rate, intercept = np.polyfit(fit_x, logit_y, 1)
    fitted_y = upper_limit / (1 + np.exp(-(growth_rate * fit_x + intercept)))
    error = np.sum((fit_y - fitted_y) ** 2)
    if best_fit is None or error < best_fit[0]:
        best_fit = (error, upper_limit, growth_rate, intercept)

fit_error, fit_limit, fit_k, fit_b = best_fit
fit_r2 = 1 - fit_error / np.sum((fit_y - fit_y.mean()) ** 2)
curve_year = np.sort(np.unique(np.append(np.linspace(fit_year.min(), 2030, 400), fit_year.max())))

fit_curve = pd.DataFrame({"year": curve_year, "share": curve_share})

# 1.3 滚动验证、模型比较与12个月预测区间展示
# 未来单月销量使用95%预测区间：它描述“下一次实际观测值”可能落入的范围，
# 因此比仅描述平均趋势的置信区间更适合本图。
from scipy.stats import t as student_t

def prediction_interval(model, x_history, y_history, x_future, confidence=0.95):
    """线性回归的预测区间；保留参数估计误差与未来随机波动。"""
    x_train_design = np.column_stack([np.ones(len(x_history)), x_history.to_numpy(dtype=float)])
    x_future_design = np.column_stack([np.ones(len(x_future)), x_future.to_numpy(dtype=float)])
    fitted = model.predict(x_history)
    degrees_of_freedom = max(len(y_history) - np.linalg.matrix_rank(x_train_design), 1)
    residual_standard_error = np.sqrt(np.sum((y_history.to_numpy() - fitted) ** 2) / degrees_of_freedom)
    covariance = np.linalg.pinv(x_train_design.T @ x_train_design)
    leverage = np.einsum("ij,jk,ik->i", x_future_design, covariance, x_future_design)
    critical_value = student_t.ppf((1 + confidence) / 2, degrees_of_freedom)
    prediction_standard_error = residual_standard_error * np.sqrt(1 + leverage)
    prediction = model.predict(x_future)
    return prediction, prediction - critical_value * prediction_standard_error, prediction + critical_value * prediction_standard_error

# 4.2 绘制Kaplan–Meier曲线并拟合Cox比例风险近似模型
from scipy.optimize import minimize

def kaplan_meier(data):
    data = data.dropna(subset=["观察时长（月）", "退出事件"]).sort_values("观察时长（月）")
    at_risk = len(data)
    survival = 1.0
    records = [{"月份": 0, "存续概率": 1.0}]
    for duration, group in data.groupby("观察时长（月）", sort=True):
        events = int(group["退出事件"].sum())
        censored = len(group) - events
        if at_risk > 0 and events:
            survival *= 1 - events / at_risk
        records.append({"月份": duration, "存续概率": survival})
        at_risk -= events + censored
    return pd.DataFrame(records)

km_curves = []
for price_band, group in lifecycle.dropna(subset=["价格档位"]).groupby("价格档位", observed=True):
    if len(group) >= 8:
        curve = kaplan_meier(group)
        curve["价格档位"] = str(price_band)
        curve["车型数"] = len(group)

def negative_cox_partial_likelihood(beta):
    score = cox_x @ beta
    loss = 0.0
    for event_time in np.unique(cox_duration[cox_event == 1]):
        event_mask = (cox_duration == event_time) & (cox_event == 1)
        risk_mask = cox_duration >= event_time
        loss -= score[event_mask].sum() - event_mask.sum() * np.log(np.exp(score[risk_mask]).sum())
    return loss

cox_result = minimize(negative_cox_partial_likelihood, x0=np.zeros(len(cox_features)), method="BFGS")

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error

tesla_history = monthly_series.query("对象 == '特斯拉中国'").sort_values("时间").reset_index(drop=True)
market_history = monthly_series.loc[
    monthly_series["对象"].eq("EV市场")
    & monthly_series["时间"].ge(tesla_history["时间"].min())
].sort_values("时间").reset_index(drop=True)
forecast_dates = pd.date_range(tesla_history["时间"].max() + pd.offsets.MonthBegin(1), periods=12, freq="MS")

def strategy_features(dates, origin):
    dates = pd.DatetimeIndex(dates)
    month_index = (dates.year - origin.year) * 12 + dates.month - origin.month
    features = pd.DataFrame({"月序号": month_index.astype(float)}, index=dates)
    for month in range(2, 13):
        features[f"月份_{month}"] = (dates.month == month).astype(float)
    return features

def strategy_predict(history, future_dates, validation_months=9):
    history = history.sort_values("时间").reset_index(drop=True)
    train, holdout = history.iloc[:-validation_months], history.iloc[-validation_months:]
    if len(train) < 18:
        raise ValueError("预测需要至少18个月训练数据与9个月留出期。")

    def seasonal_previous_year(source, dates):
        previous_dates = pd.DatetimeIndex(dates) - pd.DateOffset(years=1)
        values = source.set_index("时间")["sales"].reindex(previous_dates).to_numpy(dtype=float)
        if not np.isfinite(values).all():
            raise ValueError("上年同月基准缺少所需月份。")
        return values

    baseline_holdout = seasonal_previous_year(train, holdout["时间"])
    origin = history["时间"].iloc[0]
    regression = LinearRegression().fit(strategy_features(train["时间"], origin), train["sales"])
    regression_holdout = np.maximum(0, regression.predict(strategy_features(holdout["时间"], origin)))
    validation = pd.DataFrame([
        {"模型": "上年同月", "RMSE": mean_squared_error(holdout["sales"], baseline_holdout) ** 0.5,
         "MAE": mean_absolute_error(holdout["sales"], baseline_holdout)},
        {"模型": "趋势＋月份效应", "RMSE": mean_squared_error(holdout["sales"], regression_holdout) ** 0.5,
         "MAE": mean_absolute_error(holdout["sales"], regression_holdout)},
    ]).sort_values("RMSE").reset_index(drop=True)
    selected = validation.loc[0, "模型"]
    if selected == "上年同月":
        future_sales = seasonal_previous_year(history, future_dates)

                 .groupby("manufacturer", as_index=False)
                 .agg(当期销量=("sales", "sum")))

                  .groupby("manufacturer", as_index=False)
                  .agg(上年同期销量=("sales", "sum")))

通过观察可以看出比亚迪作为龙头公司在坐标轴处于高位，同时又保持了强劲的增长势头；而反观特斯拉作为EV市场份额第二却被远远落在后面，增长率也低于行业平均水平。就目前来看，比亚迪公司依旧是特斯拉公司的最大竞争对手，同时特斯拉也要注意理想、蔚来、长安汽车等公司后来居上，特斯拉在中国EV市场的劣势十分明显。
现有数据能够比较特斯拉与市场平均价格带、车型数量、销量增长和份额，但无法判断本土化程度、产能布局或消费者偏好如何影响结果。
若后续要研究份额增长，应补充车型配置、价格调整、渠道、库存和消费者调研数据。
在技术方面，改进生产线或生产技术，与国内材料和电子制造商达成合作，降低汽车制造成本来提高利润率。利润可用于参与培养开发与技术团队、改进生产技术、扩大在国内的产业基地等举措，巩固特斯拉在高端EV的领先地位，形成良性循环。
在车型方面，扩大生产线，推出供应中国市场的低价EV车型，搭载特斯拉自研的领先行业的智能车机系统以及自动辅助驾驶来提高性价比，在不损失太多利润率的情况下和比亚迪的中低档车型进行竞争，抢夺对手的市场份额。
在本土化方面，特斯拉需要进一步提高车机系统、导航、语音助手和娱乐功能对中国用户使用习惯的适配程度。国内消费者较重视智能座舱、手机互联、语音控制和本地应用生态，特斯拉可以加强与本土互联网、地图和内容服务企业的合作，提高产品的日常使用体验。
在品牌沟通方面，特斯拉可以减少单纯依靠降价吸引消费者的方式，更多强调其在安全性、三电技术、充电网络和软件更新方面的优势。通过试驾活动、用户社群和真实使用案例，提高消费者对品牌技术实力和产品价值的认可，避免品牌长期陷入价格战。

5. 分析结论

  1. 市场位置：老牌车企；市场份额高；增长率低下
  2. 核心优势：长期自研智能座驾系统及自动辅助驾驶；高端外国车企的品牌印象；较大的市场份额
  3. 主要风险：市场份额萎缩；增长出现停滞甚至衰退；国产高端EV车企后来居上；比亚迪蚕食市场份额
  4. 主要目标：提高销量增长率；扩大市场份额；针对比亚迪的垄断做出反击

数据限制与后续方向

  • 整体汽车数据截至2023年9月，EV数据截至2023年10月；跨市场比较统一使用双方共有的1—9月记录。
  • 年度销量、年度品牌销量、年度车型销量和相关份额图中，2023年直接按“1—9月销量 ÷ 9 × 12”估算全年，即统一乘以12/9。估算结果不是实际销量。
  • 整体汽车、EV及其品牌和车型统一使用12/9的年度系数，因此2023年的渗透率、市场份额、排名和产品结构不会因年化而改变；只有年度销量规模发生调整。
  • 月度销量及同比/环比、厂商数量、价格均值和增长—份额四象限不进行年度补全，仍使用1—9月实际观测或同周期数据，并在图表标题中标明。
  • 数据中的厂商暂作为品牌代理，无法进一步区分集团、品牌和子品牌口径。
  • 部分早期记录的售价为0.00 - 0.00，加权价格分析已排除这些报价，但2015—2018年的有效价格销量覆盖率较低。
  • 销量和市场份额能够描述市场表现，但不能单独解释价格调整、产品改款、渠道变化或消费者选择的原因。
  • 2023年线性年化默认各月平均销量相近，没有考虑汽车销量的季节性；若第四季度受旺季、政策、促销或供给变化影响，实际全年销量可能与估算存在偏差。
  • 特斯拉战略分析属于基于销售数据的初步判断，后续仍需补充价格调整、配置、促销、渠道、产能、库存、政策和消费者数据。
  • 后续可继续增加同比/环比异常监控、月度经营摘要，以及用于Power BI或Tableau的指标表。
